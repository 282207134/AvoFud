## 测试环境

- Flutter 3.47.7 stable，Dart 3.13.5。
- Windows 开发环境，Android SDK 官方模拟器。
- Android 15 / API 35，`sdk_gphone64_x86_64`。
- 截图设备尺寸 1125×2436，逻辑尺寸 375×812，密度 480。
- 所有图片和字体均从 App 本地资源读取，页面内容不依赖外部图片服务。


集成测试会重置该应用的 `avofud.v1` 本地演示数据；勿在需要保留个人演示订单时直接运行。验证码为 `1490`。截图路径与 Pixso 帧对应关系见 `SCREENS.md`。

模拟器的截图缓冲有时落后一帧，因此脚本在页面稳定且素材加载后预热截图，再保存最终帧；预热帧不交付。启动页在截图场景中停留，正常启动时仍自动进入欢迎或首页。

## 实现与验证边界

- 此次完成 UI 和本地业务演示，未实现真实账号认证、短信、支付、配送或后台管理。
- 语言选择只保存偏好；当前界面文案遵循原稿英文。
- 教程是带播放/暂停、进度和收藏的分步食谱，没有真实视频文件。
- 字体采用 Nunito 静态字重替代未提供的 Cera Round Pro，因此字形并非逐像素相同。原稿缺失的 emoji 显示使用本地图片或语言代码代替。
- 统计、评论、社交数量为示例数据；商品金额、购物车、订单及奖励按本地实际操作计算。
- Android 安装包采用演示签名；商店发布仍需正式签名和真实服务接入。
- iOS 源工程已包含，当前 Windows 环境未验证 iOS 构建；Web 入口已包含，本次验收以 Android 为准。
- 开发期间 Windows `flutter_tester.exe` 曾间歇出现原生 `0xc0000005` 崩溃。最终 64 项全量测试已通过；若该本地渲染器问题复发，可独立运行指定测试或使用 Android 设备集成测试核验。

## 代码整理

已去掉 Flutter 计数器模板，统一主题、页面骨架、按钮、卡片、导航、图片与商品行。运行时只保留 shared_preferences 一个第三方依赖，不引入重复状态库或空的分层文件。原始设计截图、测试代码和文档不打入 App 资源；安装包仅包含使用的独立素材和三个静态字重。Release 构建启用默认优化及未使用图标裁剪。
